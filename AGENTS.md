# Agent Configurations

Portable agent definitions for AI-assisted development. Drop these into your AI coding tool of choice (opencode, Claude Code, Cursor, etc.).

## Agents

| Agent | File | Purpose |
|-------|------|---------|
| Engineer | `agents/engineer.md` | Full-stack app engineering (frontend + backend) |
| Cloud & IaC | `agents/cloud-iac.md` | Cloud infrastructure and Infrastructure as Code |
| Internal Tools | `agents/internal-tools.md` | Internal tooling, automation, and integrations |
| Security Review | `agents/security-review.md` | Security posture review and compliance checks |
| Scout | `agents/scout.md` | Codebase exploration, research, and discovery |

## Usage

Copy the relevant `.md` file into your AI tool's agent/system prompt configuration. Each file is self-contained and describes a persona, its expertise, and how it should approach tasks.
